<h1>Project undergoing rewrite into TypeScript</h1>

Bloxburg Horror is a fanmade, unofficial video game port of the card game Arkham Horror LCG by Fantasy Flight Games. This project in no way intends to infringe on copyright and does not make money off the property of Fantasy Flight games.
This project uses Rojo and roblox-ts to compile TypeScript to Luau in Roblox Studio. The game can be found [here](https://www.roblox.com/games/15393831445/Bloxburg-Horror)
